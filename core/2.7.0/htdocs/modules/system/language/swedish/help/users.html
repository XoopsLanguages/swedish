Hjälp: Användare

Beskrivning

XOOPS tillhandahåller inbyggda verktyg för enkel användarhantering. Dessa inkluderar möjligheten att söka efter användare med olika kriterier, skicka e-post och privata meddelanden till användare genom ett mallbaserat meddelandesystem. På din webbplats har användarna de rättigheter som hänför sig till gruppen de tilldelas till.

När det gäller användare, de har tillgång till sin profil, har viss kontroll över det mesta av informationen som kommer att vara synlig för andra användare, och har även en inkorg för att ta emot privata meddelanden från webbplatsens administratör eller från andra användare. De har förutom kontroll över vilka förändringar på sajten som kommer utlösa personliga meddelanden. Och beroende på de behörigheter som platschefen ställt in kan de se innehåll och delta i sajtens liv genom att ladda upp innehåll, skriva berättelser eller kommentarer, betygsätta innehåll och i allmänhet ge sin feedback till vad de ser på sajten.

Avancerad sökning

"Avancerad sökning" ger ett brett utbud av alternativ som du kan använda för att söka efter specifika användare eller för att filtrera ditt medlemskap. Du kan också få en komplett lista över medlemmar genom att trycka på "skicka"-knappen utan att använda något av filtren.

Redigera användare

Du kan lägga till, redigera och ta bort användare genom denna sektion av systemmodulen.

För att redigera en användare, sök efter en baserat på namnet eller andra kriterier. Du kan då välja att antingen

i) ändra sina uppgifter eller
ii) ta bort dem med den andra rullgardinsmenyn.

Om du väljer "ändra" öppnas användarens profil som du sedan kan ändra som du vill (observera att du också kan nå sidan för redigera profil från användarsidan via medlemskatalogen eller genom att klicka på ett användarnamn var som helst på sidan).
