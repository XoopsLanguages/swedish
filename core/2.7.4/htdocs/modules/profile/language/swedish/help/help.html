BESKRIVNING

Profilmodulen är till för att hantera anpassade användarprofilfält.

INSTALLERA/AVINSTALLERA

Inga speciella åtgärder krävs, följ standardinstallationsprocessen – extrahera mappen /profile i katalogen ../modules. Installera modulen via Admin -> Systemmodul -> Moduler.

Detaljerade instruktioner om hur du installerar moduler finns i XOOPS Bruksanvisning

DRIFTSINSTRUKTIONER

För att ställa in den här modulen måste du:

  • Konfigurera dina inställningar för modulen (se 'Inställningar') och eventuellt profilblocket om du tänker använda det (se 'Blockar').
  • Redigera befintliga kategorier eller lägg till nya.
  • Redigera befintliga fält eller lägg till nya. Här kan du ange vilka fält som ska vara synliga i vilken kategori, och om de ska vara synliga vid användarregistrering.
  • Definiera ordningen för registreringsstegen.
  • Och slutligen kan du ställa in behörigheter för enskilda fält - vilka är redigerbara, vilka är sökbara.

Åtgärder mot skräppost

För att minimera skräppostregistreringar, gör följande:

  • gå till Protector-modulen i Admin, gå till Inställningar och sedan längst ned vid det här alternativet: "Stoppa Forum Spam" Kontrollerar POST-data mot spammare registrerade i databasen www.stopforumspam.com.
    Ställ in den på "Förbjud IP (ingen gräns)"

  • i /class/captcha/config.php, se till att läget är inställt som "text":

    return $config = array(
    'disabled' => false, // Inaktivera CAPTCHA
    'mode' => 'text', // standardläge, du kan välja 'text', 'image', 'recaptcha' (kräver api-nyckel)
    'name' => 'xoopscaptcha', // captcha-namn
    'skipmember' => sant, // Hoppa över CAPTCHA-kontroll för medlemmar
    'maxattempts' => 10, // Maximalt antal försök för varje session
    );

  • I profilmodulen, gå till Admin och i det grundläggande steget som finns på:
    /modules/profile/admin/step.php?id=1
    ställ in "Spara efter stopp" till "Nej"


  • I Profilinställningar, ställ in alternativet "Använd Captcha efter det andra registreringssteget" till "Ja" (det är standard)
