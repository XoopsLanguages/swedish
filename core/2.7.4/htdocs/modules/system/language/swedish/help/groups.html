Hjälp: Grupper

Beskrivning

XOOPS innehåller ett medlemsregistreringssystem - du kan valfritt kräva att folk registrerar sig på din sida för att få tillgång till vissa områden eller funktioner. Till exempel kräver de flesta webbplatser att folk går med innan de får bidra med nyheter eller posta meddelanden i forumen.
Åtkomst och administrationsrättigheter till en XOOPS-webbplats ställs in genom ett flexibelt behörighetssystem baserat på "användargrupper". Standardgrupperna inkluderar anonyma användare, registrerade medlemmar och webbansvariga, men självklart kan du definiera så många grupper som du behöver för att hantera din webbplats. Varje grupp kan ges en unik uppsättning åtkomsträttigheter som styr:

- Vilka block kan ses
- Vilka moduler kan nås
- Vilka moduler kan administreras
- Vilka aspekter av systemadministration kan modifieras

Du kan ändra namnet på dessa standardgrupper, men du kan inte ta bort dem. Andra användargrupper kan också ställas in och definieras som diskuteras senare.

Anpassade grupper kan också skapas via gruppens administrationssida.
