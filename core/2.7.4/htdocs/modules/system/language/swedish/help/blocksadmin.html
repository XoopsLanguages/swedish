Hjälp: Blockerar

Beskrivning

Block är diskreta delar av innehåll som kan skapas och konfigureras i administratörsgränssnittet. Anpassade block kan skapas och består vanligtvis av text, grafik och bilder. Innehållet i dessa block kan formateras individuellt eller ärva webbplatsens formatering. Block kan också vara en del av en moduldisplayutgång. Sidan för blockadministration är där alla block konfigureras och administreras.

Block är som en tidnings förstasida: de är teasers som lockar läsarna att läsa mer kompletta berättelser på insidan. Block erbjuder små bitar av dynamiskt innehåll med länkar till det faktiska innehållet som lagras i modulen.

En del av det som händer under huven eller bakom gardiner när en modul installeras på en XOOPS-sajt är att modulens block är registrerade i systemet, så att de kan användas efter behag av webbmastern.

Vad kan en webbansvarig göra med ett block? Tja, för det mesta, bestäm dig för var på webbplatsen blocket ska visas (motsvarande att definiera ett skyltfönster, som i det här fallet kan vara på utsidan, startsidan eller till och med på insidan: ett block kan definieras för att visas i andra moduler), och när visas, var på en sida kommer det att synas.

Varje modul som är installerad på en XOOPS-webbplats registrerar sina block i systemet, och webbmastern kan bestämma var den ska visas, i vilken del av sidan den ska visas och vilken typ av relevans, vikt eller position den kommer att ha. Webbplatsadministratören kan också redigera blockets titel och, om kunnig nog, kan även redigera mallen som ligger till grund för blockets presentation.

Tips

Du kan dölja titeln som visas när blocket visas genom att lägga till "// " (det vill säga slash-slash-space) som de tre första tecknen i titeln. På så sätt kan du sömlöst sammanfoga flera block för att bygga den vy du vill ha.

Du kan skapa dina egna innehållsblock med "Lägg till block"-knappen. Du kan skapa ditt eget innehåll i HTML, vanlig text med XOOPS-koder eller till och med PHP. I dina anpassade block, koden "{X_SITEURL}" kommer att ersättas med din webbplats URL med ett snedstreck.
