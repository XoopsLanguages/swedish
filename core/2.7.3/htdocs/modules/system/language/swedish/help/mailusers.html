Hjälp: Skicka e-post till användare

Beskrivning

XOOPS har ett inbyggt meddelandesystem som gör att du kan skicka ett meddelande till hela din registrerade användarbas eller undergrupper därav, eller använda datumfilter. Detta kan vara i form av ett privat meddelande (dvs genom XOOPS inbyggda meddelandesystem) eller via e-post. En rad alternativ är tillgänglig för att filtrera bort undergrupper av användare från ditt medlemskap.

Du kan också använda fördefinierade taggar som gör att du kan anpassa ditt meddelande.
